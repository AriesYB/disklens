## 一、双口径统计——数字终于对得上了

**一句话**：扫描总量和资源管理器看到的"已用空间"对不上的谜题，现在每个数字都给得出处。

**用户向表述**：
- 顶栏直接显示：`根目录总计 231.9 GB（占用 232.1 GB）· 卷已用 249.2 GB · 未计入 17.3 GB`
- 「未计入」悬停有解释：还原点、NTFS 元数据（$MFT/USN 日志）、无权限目录
- ⛔ N 个目录无权限 → 点击弹出完整清单（路径/已读部分大小/定位/进入）
- WinSxS 硬链接不再双计：≥1MB 文件开句柄查文件身份全局去重
- OneDrive 云占位文件占用计 0（☁ 标记），本地没下回来就是不占地方
- 列表新增「占用」列 + 状态标记（⛔ 受限 / ☁ 云端 / ⛓ 硬链接），tooltip 双口径

**技术亮点（V2EX 向）**：
- 一次 `CreateFileW(FILE_READ_ATTRIBUTES)` 同时拿 AllocationSize / 链接数 / (卷序列号, 文件索引)，只对 ≥1MB 文件开句柄，扫描开销近乎为零
- 事件协议 `al/dup/cloud/denied` 按需序列化，bool 标记 false 时省略，payload 增量极小
- 压缩/稀疏文件按逻辑大小近似（拿不到便宜的真实占用），普通文件簇对齐

## 二、WizTree 对标——搜索 / 类型统计 / 导出

**一句话**：不只是看图，找东西、看分布、出报表都是一等公民。

**功能清单**：
- **大文件榜搜索**：子串/`*`/`?` 通配；**目录名也参与**——搜 `node_modules` 直接列出所有同名目录（含体积），双击进入
- **类型统计视图**（第四个 tab）：扩展名聚合（文件数/大小/占用/占比条）；单击类型行 → 自动预填 `*.ext` 过滤大文件（类型→文件钻取）
- **CSV 导出**：大文件榜（含搜索结果全量）/ 类型统计 → 原生保存对话框，UTF-8 BOM + CRLF，Excel 直接打开不乱码；浏览器演示模式回退剪贴板

**实测数据**：C 盘 50 种类型聚合秒出；pst（云占位）占用列正确显示 0 B。

## 三、AI 联动通道——本季主打 ⭐

**一句话**：把 DiskLens 变成 AI 助手的"磁盘之眼"和"执行之手"——AI 拉实时数据、出方案，你勾选确认，应用内事务引擎执行迁移。

**完整闭环**：
```
AI: GET /api/status（没扫？POST /api/scan 自己触发，轮询进度）
 → GET /api/tree（不带 path：根下 3 层全景一次到手；?depth=1..=8&min=字节 可调）
 → 需要更细？GET /api/tree?path=…&depth=N 多层级精准下钻（含大文件 file 标记；
   <min 聚合进 agg、超出单列上限计 more、节点预算截断标 truncated——信息完备不刷屏）
 → 全量统计口径才拉 GET /api/scan（树形快照+类型+卷口径+受限目录，MB 级）
 → POST /api/proposal（migrate/cleanup/note 三类提案）
 → DiskLens 弹确认面板 → 你勾选 → 串行执行（预检→复制→校验→junction）
 → AI 轮询 /api/proposal 拿执行结果
```

**差异化卖点**：
1. **AI 不碰文件系统**——执行者是 DiskLens 自己的事务迁移引擎（复制→校验→junction 切换，任何失败源目录原样保留，跨卷断点续传）。AI 只出主意，边界清晰
2. **树形快照**不是扁平排行——AI 直接看到"Docker 目录里 ext4.vhdx 占 12.4GB"这种层级构成，不用自己 du
3. **状态驱动**——AI 先查状态再行动：没数据自己触发扫描、扫描中不重复触发；提示词明令"拿到通道数据前禁止自己扫盘"
4. **双场景入口**：顶栏「🤖 AI 分析」直达全盘分析（迁很多个/不知道迁什么）；右键目录分「全盘分析（通道，推荐）/ 深度处理此目录（skill）」——junction 批量迁移走通道，改 GRADLE_USER_HOME 这类配置重定向走 skill，各司其职
5. **提示词内置分流规则**：配置重定向类（GRADLE_USER_HOME/PIP_CACHE_DIR/Docker/WSL）强制放 note 项写改法，不许提 migrate——防止 AI 把只能官方迁移的东西瞎搬

**安全三道门**（对安全敏感的程序员受众重点讲）：
- 仅绑定 127.0.0.1 + 随机端口
- Host 头白名单（防 DNS rebinding，含 IPv6 方括号形式处理）
- `X-DiskLens-Token` 会话令牌（自定义头天然阻断浏览器 CSRF form）+ 面板开关一键停用

**零依赖实现**：手写 std TcpListener 迷你 HTTP 服务（约 300 行），不引入 tokio/axum——与项目"前端零框架、无构建步骤"的哲学一致。Rust 侧对快照零解析原样回传。

**实测数据**：真实 C 盘 231.9GB 树形快照 1.3MB（2 万节点预算封顶）；WinSxS 层 agg 聚合 18575 个小项一目了然；`/api/tree?path=…&min=0` 可列出 1~5MB 小目录（默认 min=10MB 与快照同粒度，`min` 参数按需放开）。

## 四、启动焦点策略——细节体贴

**一句话**：自动更新重启不再抢你正在用的窗口。

- 双击启动 → 正常到前台（符合预期）
- 自动更新后重启 → 自动带 `--no-focus`，`SW_SHOWNOACTIVATE` 显示不激活
- 开机自启快捷方式加 `--no-focus` 参数同样生效
- （Windows 前台锁定策略兜底：后台进程拉起的窗口本来就不允许抢前台）
